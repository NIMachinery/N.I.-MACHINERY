N.I. Machinery Website
======================

Files:
- index.html
- business-banner.png

How to use:
1. Keep index.html and business-banner.png in the same folder.
2. Open index.html in Chrome/Edge to preview the website.
3. Upload both files to your web hosting public_html/www folder to publish.

The website is responsive for mobile and desktop and includes:
- Your uploaded business banner
- Services/products
- Address and GSTIN
- Click-to-call phone numbers
- WhatsApp enquiry buttons
